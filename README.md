# digest-site — публичен сайт с дайджестите

Новини, дневен дайджест със събития, Подари Време, RADAR действия,
табло с коли и AI план за учене. Всичко, което Muse генерира като HTML,
се качва тук автоматично.

Адрес: https://frashev.github.io/digest-site/

Дизайн (от 23.11.2026, 08:36): mobile-first, топла хартия (#FBF9F3),
един тухлен акцент (#9C493D), лепкаво меню с хапчета + scrollspy.
Никой не отваря отделни HTML файлове — всичко се чете НА СТРАНИЦАТА:
малките файлове без скриптове (седмица, време, абонаменти, AI план)
се вграждат директно, а изданията (новини/дайджест) и файловете със
скриптове (Подари Време, RADAR, Коли) се показват във вграден iframe
с автоматична височина (родителят мери same-origin, без промени по
генераторите). Търсене + филтри (сутрин/следобед/вечер/събития) над
картите; филтрите на дайджеста (дни, категории) работят вътре в него.
RSS: `feed.xml` (последните 20 новини). Фавикон: `favicon.svg` + ICO +
PNG комплект (`build-favicon.py`) — теракота квадрат с бяло „Д".

Файлове в тази папка (източници — същите имена в `~/workspace/scripts/site/`):
- `build-index.py` — генерира `index.html` + `feed.xml` (сканира папката,
  класира изданията, вгражда малките файлове, останалото — iframe).
- `build-favicon.py` — рисува комплекта икони (PIL + DejaVu Bold).
- `build-weather.py` — прогноза за София (Open-Meteo, wttr.in резерва).
- `publish.ps1` — генерира индекса, commit-ва и push-ва.
- `site-sync.py` — НЕ е тук, а при Muse; той копира файловете насам.

Как работи:
- Muse генерира HTML файловете в своя workspace.
- `site-sync.py` (на Muse, на всеки час) копира новите/променените
  файлове в тази папка през SSH и пуска `publish.ps1`.
- `publish.ps1` (на този компютър) генерира `index.html` през
  `build-index.py`, commit-ва промените и ги push-ва към GitHub.
- GitHub Pages сервира сайта. Push-ът става от този компютър през
  SSH ключ (`~/.ssh/id_rsa_github`), затова не иска одобрения
  в чата на Muse и не иска `gh auth login`.
